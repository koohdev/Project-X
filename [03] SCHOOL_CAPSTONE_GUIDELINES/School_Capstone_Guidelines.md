## 📋 Project Categories and Requirements

### 1. Transaction Processing Systems (TPS)

Computer-based versions of manual organization systems dedicated to handling the organization's transactions.

**General Requirements:**
- Complete file structure (normalized tables, master and transaction files)
- Back-up and recovery features
- Archiving capabilities
- Complete data entry components with validation and error trapping
- Proper maintenance features
- Complete reports generation
- Security, data accuracy, and integrity features
- Network set-up

#### TPS Project Types:

| Project Type | Minimum Requirements | Valid Test Data |
|-------------|---------------------|-----------------|
| **Payroll System** | 50 employees, time keeping, payslip generation, SSS/Tax tables | 50 employees |
| **Sales & Inventory** | 1,000 items, 5-10 product lines, reorder points | 5-10 product lines |
| **Library System** | 2,000 books (CHED), 500 members, borrowing/returning | 50 titles, 50 borrowers |
| **Accounting System** | AR/AP monitoring, aging technique, journal posting | 30 accounts |
| **Enrollment System** | 200 students, 2 sections/year, registration, scheduling | — |
| **Hotel Reservation** | 20 rooms, 100 customers, auto-billing | 50 customers |
| **Patient/Hospital** | 20 beds, 50 patients, medication, auto-billing | 50 patients |

---

### 2. Management Information Systems (MIS)

Computer-based systems designed to provide standard reports for managers about transaction data.

**Required Report Types:**
- Trend analysis reports
- Summary reports
- Exception reports
- On-demand reports
- Ad-hoc reports

---

### 3. Decision Support Systems (DSS)

Systems designed to help organization decision-makers make decisions.

**Required Components:**
- Database
- Model base
- Dialogue module

---

### 4. Geographical Information Systems (GIS)

Computer systems capable of assembling, storing, manipulating, and displaying geographically referenced information.

**Required Features:**
- Information retrieval
- Topological modeling
- Networks and overlay (map layers)
- Algorithms (e.g., shortest path)
- Data output

---

### 5. Multimedia Systems

Software encapsulating various digital media (text, images, audio, video, graphics, animation).

**Required Features:**
- Incorporation of **at least 4 media types** (text, graphics, audio, video)
- Maintenance features and dynamic content management
- Database(s) for storing information
- Search features, save and print functions
- User levels (administrator, viewers/researchers)
- Copyright compliance for materials used

---

### 6. Computer-Aided Instruction (CAI)

Software designed to facilitate learning using multimedia integration.

**Required Features:**
- At least 4 media types
- 2-3 methods of presenting topics
- Major categories: drills/practice, tutorials, simulation, games
- Target age bracket identification
- Level of difficulty for lessons and test items
- Random generation of test items
- Analysis of results and user performance feedback
- **Testing: 50 items per topic**

**Design Tools:**
- Storyboarding, flowcharting, HIPO
- ⚠️ **Data flow diagrams must NOT be used** for modeling CAI features

---

### 7. Web Applications

**General Requirements:**
- Multimedia system considerations
- Dynamic pages (database-driven content)
- Maintenance features
- Standard conformance, portability, clear navigation
- Search engine functionality
- Report generation
- Meta tags and hyperlinks
- E-consultation module (bulletin/message board, email inquiry)
- Security features
- **Must be uploaded/deployed**

**Acceptable Web Projects (Host Company Required):**

| Project | Key Requirements |
|---------|-----------------|
| **Online Ordering System** | Inventory (1,000+ items), product catalog, order tracking, payment |
| **Online Hotel Reservation** | Room management, interactive maps, online approval/cancellation |
| **Online Job Application** | 100+ applicants, 10+ job offerings, job matching, applicant tracking |
| **Online Registration (Pre-Enrollment)** | Tertiary level only, curriculum tracking, student info system |

### 9. Software Engineering

Establishment of sound engineering principles for reliable, economical software.

**Focus Areas:**
- New programming paradigms
- Cost models
- Systems software (OS, compilers, interpreters, utilities)
- Other packages (desktop publishing, graphics, CAD, etc.)

---

### 10. Systems Analysis and Design

Complex organizational process for developing and maintaining computer-based information systems.

**Focus:** Automated tools combining process and data views

---

### 11. Networking

Process of connecting computer devices for data transfer.

**Focus:** Network topology implementation

## 📝 AI Output Guidelines (Cross-Reference Compliance)

When generating capstone document content, the AI must:

1. **Verify Project Compliance** — Ensure the described system meets the minimum requirements for its category (e.g., TPS payroll = 50 employees minimum)

2. **Include Required Features** — When describing scope/objectives, reference the mandatory features listed for the project type

3. **Use Correct Terminology** — Match the DCT manual terminology (e.g., "peopleware," "hardware," "software" structure)

4. **Reference Test Data Requirements** — Include appropriate test data volumes in methodology/testing sections

5. **Avoid Unacceptable Patterns** — Do not generate content that matches rejected project types

6. **Cross-Reference Sample Document** — Align output structure and academic tone with the Capstone 1 Sample PDF while maintaining compliance with these official requirements
