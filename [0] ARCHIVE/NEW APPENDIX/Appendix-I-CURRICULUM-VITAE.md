## GUIDELINES FOR CURRICULUM VITAE

Use the student's complete name. The name should be consistent with the official school records.

**Keep the CV concise and professional**. A recommended length is 1–2 pages per student, unless otherwise required.

**Use accurate information only**. Students should not include fabricated educational backgrounds, skills, certifications, employment, awards, or affiliations.

**Use a professional format**. Maintain consistent font, spacing, margins, headings, and alignment.

**Prioritize relevant information**. Technical skills, IT-related training, certifications, academic achievements, and Capstone-related experience should be emphasized.

List educational background in reverse chronological order. Start with the most recent educational attainment.

**Use consistent date formats**. For example:

August 2024 – Present

2024–2026

August 2026

**Technical skills should be truthful**. Students should indicate only technologies, programming languages, software, and tools they actually know or used.

Include Capstone-related responsibilities. Clearly indicate the student's role in the development of the project, such as:

Project Manager

Programmer

Database Designer

UI/UX Designer

Systems Analyst

Documentation Lead

Tester/Quality Assurance

**Include only relevant references**. References should be individuals who can appropriately verify the student's academic or professional experience.

Obtain permission before listing references. Students should ask the person for permission before including their contact information.

**Protect personal information**. Avoid including unnecessary sensitive information such as government identification numbers, passwords, bank information, or other confidential data.

Use a professional photograph only if required. If a photograph is required by the institution, use a clear and appropriate formal photo.

**Do not exaggerate qualifications**. Skills and achievements should accurately represent the student's experience.

Maintain consistency among group members. For a group Capstone Project, all members should use the same CV template and formatting.

**Arrange the CVs consistently**. Each group member should have a separate Curriculum Vitae using the same structure.
