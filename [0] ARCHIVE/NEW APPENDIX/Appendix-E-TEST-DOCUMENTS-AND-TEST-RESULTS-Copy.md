## GUIDELINES FOR APPENDIX E

Include the actual evaluation and testing instruments. Do not include only a summary of the results.

**Provide evidence of actual testing**. Completed test cases, evaluation forms, UAT documents, and other relevant records should be included when required.

**Indicate the testing status clearly**. Each test case should indicate whether the expected result was achieved.

**Do not fabricate testing results**. Test results must reflect the actual testing conducted by the researchers and evaluators.

**Include signatures when applicable**. Evaluation and UAT documents requiring validation or approval should contain the appropriate evaluator's signature and date.

**Protect confidential information**. Personal information that is not necessary for the documentation should be removed or properly redacted.

**Arrange documents logically**. A recommended order is:

Evaluation Questionnaire

Testing Results

Bug/Error Reports

Supporting Testing Evidence (PHOTOS)

**Use readable copies**. Scanned documents, screenshots, and reproduced forms must be clear and readable.

Do not overload the appendix with unnecessary screenshots. Include screenshots only when they serve as evidence of testing or evaluation.

Reference the appendix in the main manuscript. When discussing the evaluation or testing process, refer the reader to the appropriate appendix.

Example:The researchers conducted User Acceptance Testing using the prepared UAT instrument (see Appendix E-3).

**Maintain document consistency**. The project title, system name, module names, criteria, and terminology should be consistent throughout the manuscript and appendices.

Follow the required formatting of the Capstone Manual. Font, margins, spacing, page numbering, table format, and heading styles should follow the prescribed institutional format.
