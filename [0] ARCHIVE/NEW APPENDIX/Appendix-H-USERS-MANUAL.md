# Appendix H: User’s Manual

This User’s Manual provides comprehensive operational guidance and interface documentation for *Chronicles of Arithmos: A 2D Role-Playing Game with Dynamic Math-Based Combat System and Adaptive Difficulty Scaling*. It guides young learners, players, educators, and evaluators through every interface screen, operational workflow, combat mechanic, and configuration setting of the system across desktop and mobile platforms.

---

### Figure No.: Figure H-1

### Figure Title: Title Screen Interface Navigation

![Figure H-1: Title Screen Interface Navigation](images/Fig-H1-Title-Screen.png)

**Narrative Overview and Operational Context:**  
The Title Screen is the main entry portal of the application. It displays the title banner over the royal citadel environment with the celestial holy sword in stone. The interface provides four primary navigation options: New Game, Continue, Options, and Exit.

**Operating Procedures:**  
1. **Starting a New Adventure:** Navigate to **New Game** using keyboard directional keys (`Up`/`Down`) or touch tap, then press `Z`, `Enter`, or `Spacebar` to open the Protagonist Character Name Input screen.
2. **Restoring Previous Progress:** Select **Continue** to open the Continue and Load Game interface, displaying recorded autosaves and manual save files.
3. **Configuring Settings:** Select **Options** to modify audio balance, display HUD elements, and customize touch controls.
4. **Closing the Application:** Select **Exit** on desktop builds to cleanly shut down and terminate the application window.

### Figure No.: Figure H-2

### Figure Title: System Options Menu (General & Audio Settings)

![Figure H-2: System Options Menu (General & Audio Settings)](images/Fig-H2-Options-General.png)

**Narrative Overview and Operational Context:**  
The System Options Menu allows players to configure operational gameplay parameters and audio volume levels. The configuration is automatically persisted to local client storage.

**Operating Procedures:**  
1. **Toggling Continuous Running:** Select **Always Dash** and press `Z` or tap to switch between `ON` and `OFF` for automatic character dashing.
2. **Managing Battle Memory:** Toggle **Command Remember** to retain the last selected combat command position during turn transitions.
3. **Configuring Touch UI:** Toggle **Touch UI** to display on-screen virtual navigation pads and combat menu overlays on mobile devices.
4. **Displaying Health Indicators:** Toggle **Show HP Gauge** to render real-time health bars above active combatants in battle.
5. **Adjusting Audio Volumes:** Select **BGM Volume**, **BGS Volume**, or **ME Volume** and use `Left`/`Right` arrow keys or touch sliders to calibrate background music, atmospheric effects, and musical event sounds from 0% to 100%.

### Figure Title: System Options Menu (Sound Effect Setting)

![Figure H-3: System Options Menu (Sound Effect Setting)](images/Fig-H3-Options-SE.png)

**Narrative Overview and Operational Context:**  
The second section of the System Options Menu governs the sound effect (SE) audio channel, which outputs math submission feedback, UI selection clicks, and battle ability audio.

**Operating Procedures:**  
1. **Calibrating Sound Effects:** Select **SE Volume** and adjust the horizontal slider using `Left`/`Right` directional inputs or screen tapping. The default level is set to 40% to balance audio comfort during math exercise feedback.

### Figure No.: Figure H-4

### Figure Title: Continue and Load Game Interface

![Figure H-4: Continue and Load Game Interface](images/Fig-H4-Load-Game.png)

**Narrative Overview and Operational Context:**  
The Continue and Load Game Interface lets players restore saved progress files from local storage. The menu lists a dedicated Autosave slot followed by twenty manual save slots (File 1 through File 20) with active party previews and total playtime timestamps.

**Operating Procedures:**  
1. **Loading Autosaved Checkpoints:** Highlight the **Autosave** slot at the top of the list and press `Z` or double-tap to resume from the latest automatic milestone.
2. **Selecting Manual Save Slots:** Scroll through the save slot listing using `Up`/`Down` arrow keys or swipe gestures. Active slots showcase hero portraits, party levels, current map location, and gameplay timestamps.
3. **Confirming File Load:** Press `Z` or tap the target slot to immediately reconstruct party stats, quest states, and world progress.
4. **Canceling Load Operation:** Press `X`, `Escape`, or tap the on-screen Back button to return to the Title Screen.

### Figure No.: Figure H-21

### Figure Title: Math Battle System & Mobile Virtual Numeric Keypad Interface

![Figure H-21: Math Battle System & Mobile Virtual Numeric Keypad Interface](images/Fig-H21-Math-Combat-Keypad.png)

**Narrative Overview and Operational Context:**  
The Math Battle System and Mobile Virtual Numeric Keypad Interface executes whenever the player initiates an offensive strike or tactical ability. It challenges the young learner with curriculum-aligned arithmetic problems while managing an adaptive Content-Aware Timer.

**Operating Procedures:**  
1. **Reading the Arithmetic Prompt:** Observe the generated arithmetic problem (e.g., `3 + 3 = ?`) displayed in the central challenge window.
2. **Monitoring the Content-Aware Timer:** Observe the upper green timer bar. The timer tracks response latency to award critical hit multipliers ($2.0\times$) for rapid and accurate mental math computations.
3. **Entering Numerical Answers:** Input numeric answers using the touch virtual keypad grid (`0` through `9`, minus `-`), or by typing directly on a physical keyboard or numpad.
4. **Correcting Input:** Tap **DEL** or press `Backspace` on a keyboard to erase incorrect digits.
5. **Submitting Answer:** Tap the **OK** button or press `Enter` to submit the solution to the Math Engine. Correct solutions unleash devastating critical strikes; incorrect answers trigger adaptive scaffolding and reduced attack potency.
