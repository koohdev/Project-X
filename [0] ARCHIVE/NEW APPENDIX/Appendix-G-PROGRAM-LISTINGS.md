## GUIDELINES FOR PROGRAM LISTINGS

**Include actual source code**. Program listings must represent the code actually used in the developed system.

**Organize code logically**. Arrange source code according to modules, features, or functions rather than presenting it randomly.

**Include only relevant code**. Focus on major and essential programs, modules, functions, and components required by the system.

**Avoid unnecessary duplication**. Do not repeatedly include identical code appearing in multiple files unless the duplication is necessary for understanding the implementation.

For very large systems, do not unnecessarily reproduce the entire codebase. Include the major source-code components required by the Capstone documentation guidelines and provide the complete source code through the prescribed submission method when required.
